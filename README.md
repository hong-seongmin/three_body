# 3체 문제 시뮬레이션

3체 문제(Three-Body Problem)의 복잡성과 혼돈적 특성을 시각적으로 보여주는 인터랙티브 3D 시뮬레이션입니다.

## 기능

### 🎮 인터랙티브 3D 시각화
- Three.js를 사용한 실시간 3D 렌더링
- 자유로운 카메라 회전 및 줌
- 3개의 천체가 중력으로 상호작용하는 모습을 입체적으로 관찰

### ⚙️ 완전한 초기값 제어
각 천체에 대해 다음을 설정 가능:
- **질량** (100kg ~ 5000kg)
- **크기** (시각적 표현)
- **위치** (X, Y, Z 좌표)
- **초기 속도** (X, Y 방향)

### 🎯 직관적 조작
- 슬라이더를 통한 실시간 파라미터 조정
- 마우스 드래그로 천체 위치 직접 조정
- 변경사항 즉시 반영

### 🌟 궤적 추적
- 각 천체의 이동 경로를 선으로 표시
- 궤적 표시 On/Off 토글 기능
- 최대 500개 포인트까지 궤적 기록

### 📊 실시간 물리량 모니터링 (NEW!)
**시뮬레이션 통계**
- 경과 시간 표시
- 총 에너지 (보존되어야 하는 값)
- 에너지 오차율 (수치 적분 정확도 지표)
  - 초록색: < 0.1% (매우 정확)
  - 노란색: 0.1% ~ 1% (양호)
  - 빨간색: > 1% (오차 증가)
- 운동 에너지 (KE = ½mv²)
- 위치 에너지 (PE = -Gm₁m₂/r)

**물체별 정보**
- 실시간 위치 좌표 (X, Y, Z)
- 속도 크기
- 개별 운동 에너지

**물체 간 거리**
- 물체 1-2, 1-3, 2-3 간 실시간 거리
- 충돌 위험 감지

### 📈 실시간 그래프 (NEW!)
**에너지 변화 그래프**
- 총 에너지 (청록색): 보존 확인
- 운동 에너지 (빨강): 속도 변화
- 위치 에너지 (파랑): 거리 변화
- 에너지 교환 과정 시각화

**물체 간 거리 그래프**
- 3개 물체 쌍의 거리 변화 추적
- 근접 조우 패턴 분석
- 궤도 주기성 파악

### 🎯 벡터 시각화 (NEW!)
- **속도 벡터** (밝은 화살표): 물체의 운동 방향과 속력
- **힘 벡터** (어두운 화살표): 중력의 방향과 크기
- 벡터 표시 On/Off 토글
- 동적 스케일링

### 🎯 질량 중심 표시 (NEW!)
- 노란색 와이어프레임 구체
- 시스템의 무게중심 실시간 추적
- 외력이 없으므로 질량 중심은 정지 또는 등속 운동

### ⏯️ 시뮬레이션 컨트롤
- **재생/정지**: 시뮬레이션 시작 및 일시정지
- **리셋**: 초기 상태로 되돌리기
- **시간 속도**: 0.1x ~ 3.0x 배속 조절

### 📋 사전 설정 프리셋
흥미로운 3체 문제 구성들:
- **Figure-8 궤도**: 세 천체가 8자 형태로 움직이는 안정적 궤도
- **라그랑주 삼각형**: 정삼각형 형태를 유지하는 안정적 구성
- **혼돈 궤도**: 예측 불가능한 혼돈적 움직임

## 사용 방법

### 기본 조작
1. **시점 조절**
   - 좌클릭 드래그: 카메라 회전
   - 우클릭 드래그: 카메라 이동
   - 마우스 휠: 확대/축소

2. **천체 조작**
   - 천체를 클릭한 후 드래그하여 위치 조정
   - 오른쪽 패널의 슬라이더로 세밀한 조정

3. **시뮬레이션**
   - ▶ 재생 버튼을 눌러 시뮬레이션 시작
   - 시간 속도를 조절하여 빠르거나 느리게 관찰
   - 궤적 표시를 켜서 이동 경로 확인

### 프리셋 활용
1. 하단의 프리셋 버튼 클릭
2. 자동으로 설정값 적용
3. 재생 버튼을 눌러 시뮬레이션 관찰

### 커스텀 설정
1. 각 천체의 질량, 위치, 속도를 원하는 대로 조정
2. 리셋 버튼을 눌러 초기화
3. 재생하여 결과 확인

## 물리 엔진

### 구현된 물리 법칙
- **뉴턴의 만유인력 법칙**: F = G × (m₁ × m₂) / r²
- **Velocity Verlet 적분법**: 높은 정확도의 수치 적분
- **충돌 방지**: 최소 거리 제한으로 안정성 확보

### 보존량 계산
- **총 에너지**: E = KE + PE (보존됨)
- **운동 에너지**: KE = Σ(½mᵢvᵢ²)
- **위치 에너지**: PE = -Σ(Gmᵢmⱼ/rᵢⱼ)
- **운동량**: p = Σ(mᵢvᵢ) (보존됨)
- **각운동량**: L = Σ(rᵢ × mᵢvᵢ) (보존됨)
- **질량 중심**: rcm = Σ(mᵢrᵢ) / Σ(mᵢ)

### 특징
- 정밀한 중력 계산
- 실시간 시뮬레이션
- 안정적인 수치 적분
- 에너지 보존 오차 < 0.1% 유지

## 3체 문제란?

3체 문제는 세 개의 물체가 서로의 중력에 의해 움직일 때 그 운동을 예측하는 문제입니다. 2체 문제와 달리 일반적인 해석적 해가 존재하지 않으며, 초기 조건에 극도로 민감한 혼돈적 특성을 보입니다.

### 왜 어려운가?
- **비선형성**: 세 물체의 상호작용이 복잡하게 얽힘
- **초기값 민감성**: 아주 작은 초기값 차이가 완전히 다른 결과를 만듦
- **예측 불가능성**: 장기적 행동을 정확히 예측할 수 없음

이 시뮬레이션을 통해 3체 문제의 복잡성과 아름다움을 직접 체험할 수 있습니다.

## 실행 방법

1. 웹 서버를 통해 index.html 실행 (로컬 파일로도 가능)
2. 브라우저에서 열기
3. 시뮬레이션 즐기기!

간단한 로컬 서버 실행:
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

그 후 브라우저에서 `http://localhost:8000` 접속
